# Архив ИРД

Flask-приложение для загрузки PDF с исходными данными проектного института, OCR-распознавания, смысловой классификации документа и сохранения реквизитов в SQLite.

## Возможности

- Несколько проектов с отдельными архивами исходных документов.
- Загрузка PDF и фотографий с компьютера или телефона: JPEG, PNG, WebP и HEIC.
- Сохранение оригинала до OCR; распознанные реквизиты можно исправить в карточке документа.
- Редактируемые шаблоны списков и независимые чек-листы проектов.
- Напоминания об истекающих и просроченных документах на главной странице и в проекте. По умолчанию — за 30 дней.
- Экспорт проекта в ZIP: оригиналы, реквизиты, OCR-текст, чек-лист и манифест SHA-256.
- Архивирование проекта без удаления записей и файлов; проект можно восстановить.
- Убранные документы можно вернуть из архива вместе с их оригинальными файлами.

## Скорректированное ТЗ по примеру PDF

Пример `/Users/alexander/Downloads/47ebbc39.PDF` является сканированным PDF: 2 страницы, производитель `EPSON Scan`, текстового слоя нет, страницы лежат как изображения. Поэтому базовое ТЗ нужно дополнить обязательным OCR-этапом.

Пайплайн:

1. Пользователь вводит номер договора и наименование объекта.
2. Пользователь загружает PDF.
3. Система сохраняет файл в `instance/uploads`.
4. Система сначала пробует извлечь встроенный текст из PDF.
5. Если текстового слоя нет или он слишком короткий, система рендерит страницы и запускает OCR.
6. AI-модель извлекает реквизиты в строгий JSON: рабочее название, официальное название, кем выдан, дата выдачи, срок действия.
7. Если AI недоступен, включается локальный regex/fuzzy fallback.
8. Если срок действия не найден, документ сохраняется как `без срока действия`.
9. Данные сохраняются в SQLite в отдельных полях.

В примере виден тип документа, близкий к `Технические требования`/`Технические условия`; без русского языкового пакета OCR распознает кириллицу плохо, поэтому для эксплуатации нужен `rus.traineddata`.

## Архитектура

- `app/web` — маршруты и HTML-формы.
- `app/services/storage.py` — сохранение PDF.
- `app/services/pdf_text.py` — извлечение текстового слоя и OCR.
- `app/services/ai_extractor.py` — извлечение реквизитов AI-моделью через OpenAI Responses API.
- `app/services/field_extractor.py` — резервное извлечение регулярными выражениями.
- `app/services/classifier.py` — смысловое присвоение рабочего названия по списку вариантов.
- `app/repositories.py` — слой доступа к SQLite.
- `app/database.py` — схема базы данных.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Установите Tesseract и русский языковой пакет. На macOS:

```bash
brew install tesseract tesseract-lang
```

Создайте `.env` при необходимости:

```bash
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5.2
TESSERACT_LANG=rus+eng
USE_AI=true
```

Запуск:

```bash
flask --app run run --debug
```

Откройте `http://127.0.0.1:5000`.

Для локального извлечения реквизитов через Ollama задайте `AI_PROVIDER=ollama`,
`OLLAMA_BASE_URL=http://host.docker.internal:11434` и `OLLAMA_MODEL=qwen3.5:9b`.
При запуске без Docker используйте `http://127.0.0.1:11434`. Текст сканов по-прежнему
распознается Tesseract, после чего Ollama определяет тип и реквизиты документа.

Ежедневный список истекающих сроков можно вывести командой:

```bash
docker compose exec -T web flask --app run expiry-report
```

Её можно запускать системным планировщиком; команда не отправляет документы
во внешний сервис.

## Данные и резервная копия

База находится в `instance/documents.db`, оригиналы — в `instance/uploads`.
Скопируйте оба пути, чтобы получить полную резервную копию. Архивирование
проекта не удаляет их. Перед миграцией приложения создаётся проверенная копия
SQLite в `instance/backups`. ZIP-экспорт доступен из карточки проекта и включает
все документы проекта, в том числе убранные в архив.

## Поля базы данных

Сохраняются: номер договора, наименование объекта, исходное имя файла, рабочее название документа, официальное название документа, кем выдан, дата выдачи, срок действия, признак бессрочности, OCR-текст, статус обработки и ошибка при наличии.
